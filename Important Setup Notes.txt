Step create devcontainer
1 - Create folder with name ".devcontainer"
2 - Create in folder ".devcontainer" file name "devcontainer.json", "Dockerfile" and "post-create.sh"
3 - Press "Ctrl + Shift + P", then search "Codespace: Rebuild Container" (this step need to run for new codespace)

Step To Add Program in api folder
1 - Check .Net version using command terminal, type "dotnet --version" and "dotnet --info"
2 - Now go to root repos using command "cd /workspace/repo_name"
3 - Create folder placement api using command "mkdir folder_name"
4 - Go to assign folder using command "cd folder_name"
5 - Run command "dotnet new webapi"
6 - Run command "dotnet restore" and "dotnet build"
7 - To run webapi is using command "dotnet run"
8 - The on url add "/weatherforecast" then it will show json "weatherforecast"

Step To Add 
1 - Check Flutter version using command in terminal, type "flutter --version" and "dart --version"
2 - Run command "flutter doctor" got warning like "Android SDK", "Android Studio", "Chrome", and "Linux desktop", it normal
3 - Run command "flutter devices", then run "flutter config --enable-web", it change enable-web to true
4 - Now go to root repos using command "cd /workspace/repo_name"
5 - Create folder placement app using command "mkdir folder_name"
6 - Go to assign folder using command "cd folder_name"
7 - Run command "flutter create ."
8 - Run command "flutter run -d web-server --web-port 8080"
9 - Run command "flutter build web"

Setup Database
1 - Go to "https://supabase.com/dashboard"
2 - Login with github
3 - Add new project in supabase
4 - After finish, click back on project and find the button with name "connect"
5 - Click on it, then find tab for "connection string"
6 - For connection method, choose "session pooler"
7 - Copy connection string example:
postgresql://postgres.pdykcdbckvghcsfyhjly:[YOUR-PASSWORD]@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres
change [YOUR-PASSWORD] to real possword you create at project
8 - Add to the github codespace, open repository then click "settings". find "secrect and variable" then click on "codespace"
9 - Add name - db and secrect is connection string from supabase
10 - Need restart the codespace
11 - Need to run command "echo ${dbname:+Secret available}", if show secret available. if not show need to check "Settings → Secrets and variables → Codespaces"
